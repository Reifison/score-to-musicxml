# Instalação no iPhone físico

Toda instalação do Conversor de Partituras no iPhone do usuário deve usar uma compilação iOS Release assinada com o JavaScript incluído no pacote. O app deve abrir pelo ícone sem Metro, Expo Development Build, link de desenvolvimento ou conexão com o Mac. Use `scripts/install-ios-device-release.sh` para validar o pacote antes da instalação. Compilações Debug ficam restritas aos simuladores.
