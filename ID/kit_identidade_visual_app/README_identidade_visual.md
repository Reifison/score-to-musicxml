# Identidade visual do app - e-commerce mobile

Este kit foi criado a partir da imagem de referência enviada. A direção visual é de um app de compras moderno, leve e amigável, com predominância de branco, cards arredondados, cor principal mint/turquesa e apoio em violeta, laranja e coral.

## Arquivos

- `identidade_visual_app.pdf`: guia visual com análise, paleta, tipografia e componentes.
- `design-tokens.json`: tokens para uso por design/dev.
- `design-tokens.css`: variáveis CSS prontas para front-end.
- `logo-mark.svg`: símbolo simples de referência para o app.
- `preview.html`: página rápida para visualizar botões, cards e paleta.

## Paleta principal

| Token | Nome | Hex | Uso |
|---|---|---:|---|
| `primary` | Fresh Mint | `#44CFB7` | CTAs principais, links de ação, barra de progresso, estados positivos |
| `primary_light` | Soft Aqua | `#82D5CF` | fundos leves, chips, highlights e elementos secundários |
| `secondary` | Soft Violet | `#9282CE` | botões secundários, cards promocionais, marcações de etapas |
| `accent_warm` | Sunset Orange | `#EB9937` | preço, promoções, badges de oferta e microinterações |
| `accent_yellow` | Warm Sand | `#EFC893` | fundos de banners, placeholders e ilustrações |
| `accent_coral` | Soft Coral | `#D3988D` | favoritos, alertas suaves, ilustrações de moda |
| `info` | Deep Sky | `#1983AD` | informações, status de entrega, ícones utilitários |
| `text` | Charcoal | `#2F2A33` | títulos e textos de alta hierarquia |
| `muted` | Cool Gray | `#8D98A7` | descrições, labels e textos auxiliares |
| `surface` | App White | `#FFFFFF` | cards e fundos principais |
| `background` | Soft Cloud | `#F6F8FB` | background do app e áreas externas aos cards |
| `line` | Light Line | `#E8EDF3` | bordas, divisores e inputs |

## Recomendações de UI

- Use `Fresh Mint` para ações principais: comprar, continuar, pagar, acompanhar pedido.
- Use `Soft Violet` para ações secundárias ou fluxos especiais, como checkout e saldo.
- Use `Sunset Orange` apenas para destaque comercial: preço, desconto, promoção.
- Mantenha fundo geral em `Soft Cloud` e cards em branco.
- Use bordas suaves e radius alto para manter a sensação premium e mobile-first.
